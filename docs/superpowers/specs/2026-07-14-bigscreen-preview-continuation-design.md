# 大屏预览续作设计

## 目标

在不重写现有迁移成果的前提下，完成 `dwbi_vis_screen` 大屏预览行为的回归：3333 方案显示两页、支持箭头和键盘左右切换，并把过快的 1000ms 自动轮播恢复为 5000ms 的可读间隔。

## 已确认现状

- 运行中的 `/vis/api/schemeInfo/getAllPage` 对 3333 返回两页，键名为前端所需的小写形式；本次不修改 SQL 别名。
- `BigScreenPreview.vue`、`BigScreenTabTemplate.vue` 及图表子组件已经迁入并在真实页面运行。
- 鼠标箭头和键盘左右键均能在两页之间切换。
- 数据库中 3333 的 `rotation_interval` 为 `1000`，Element UI 轮播组件实际收到的也是 `1000`，自动切换过快。

## 设计

轮播间隔统一由 `resolveVisCarouselInterval` 处理，最小值为 5000ms。空值、非法值以及 1000-4999ms 的历史值统一回落到 5000ms；小于 100 的秒制历史值先换算为毫秒，再应用相同下限；5000ms 及以上保持不变。展示方案编辑表单的最小可选值同步改为 5000ms，避免再写入过快配置。

不批量修改数据库，不改变 5000ms 及以上的已有配置，也不为已经正确返回的数据增加前端字段兼容分支。

## 验收

- 自动化测试覆盖空值、非法值、秒制值、1000ms、5000ms 和更大值。
- 前端构建通过。
- 浏览器中 3333 仍显示两页，箭头和键盘切换正常。
- 自动轮播开启时，组件的运行时 `interval` 为 5000ms。
